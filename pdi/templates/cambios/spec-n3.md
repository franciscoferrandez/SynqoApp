# Plantilla — Change N3

Para N3 se permite dividir artefactos:

```text
SPEC-<AREA>-<NNN>/
├── spec.md
├── questions.md
├── research.md
├── design.md
├── structure.md
├── plan.md
├── validation.md
└── convergence.md
```

### Ejemplo

Un cambio de autenticación con migración de sesiones, breaking contracts y security review justifica esta separación.
