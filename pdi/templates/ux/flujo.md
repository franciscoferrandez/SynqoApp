# Plantilla — Flujo UX

```md
---
id: FLUJO-<AREA>-<NNN>
---
# <ID> — <Denominación>
## Actor
## Entrada
## Precondiciones
## Pasos
## Resultado
## Errores
## Cancelación
## RF/RN relacionados
```

### Ejemplo

```md
# FLUJO-DIS-001 — Responder disponibilidad
1. Abrir evento.
2. Revisar opciones.
3. Indicar disponibilidad.
4. Guardar.
```
