# Plantillas

Las plantillas **no son fuente de verdad**. Sirven de guía para `pdi:baseline-update`, `pdi:product-continue` y skills de Change.

Cada plantilla contiene un ejemplo breve claramente marcado. Los ejemplos no deben copiarse como hechos del proyecto.

Incluye también `<PDI_ROOT>/templates/gobierno/` para catálogos, preguntas, hipótesis, conflictos y trazabilidad.

`AGENTS.project.md` es la guía mínima que `pdi:init` instala en la raíz de un proyecto cuando no existe `AGENTS.md`. Explica cómo encontrar y consultar la documentación del proyecto; no contiene reglas del framework ni del producto.
