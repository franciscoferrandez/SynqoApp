# Mandamientos globales

1. **Primero intención, después código.**
2. **Primero hechos, después solución.**
3. **Una verdad, una fuente normativa.**
4. **ID sin denominación no es una referencia legible.**
5. **Hipótesis no es hecho.**
6. **Research no es decisión.**
7. **ADR no es research.**
8. **Baseline no es delivery.**
9. **Change no autoriza scope creep.**
10. **Código y docs en conflicto requieren resolución, no maquillaje.**
11. **Cada módulo tiene reglas propias además de las globales.**
12. **Un gate solo se omite activamente, con motivo.**
