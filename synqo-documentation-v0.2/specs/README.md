# Specs

Las SPEC son unidades implementables que conectan requisitos, diseño, criterios de aceptación, tests y evidencia. El [`spec-register.md`](spec-register.md) es el índice y `SPEC-TEMPLATE.md` es la plantilla.

No se redacta una SPEC por cada requisito automáticamente. Se crea una cuando una unidad de comportamiento necesita una decisión y un contrato implementables. Las referencias a las fuentes evitan duplicación.

Estados y transición están definidos en [`../development/spec-driven-development.md`](../development/spec-driven-development.md).
