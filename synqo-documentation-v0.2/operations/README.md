# Operations

Esta carpeta se completará durante Deployment y operación controlada. No contiene todavía procedimientos ejecutables ni resultados ficticios.

Como mínimo, cuando llegue esa fase contendrá:

- `deployment.md`: despliegue real y configuración por entorno;
- `runbook.md`: operación, diagnóstico y recuperación cotidiana;
- `backup-and-restore.md`: copias, retención y restauración verificada.

Los procedimientos deberán basarse en el entorno y scripts realmente existentes, no en comandos hipotéticos.
