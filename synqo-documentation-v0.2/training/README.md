# Material formativo de Synqo

Este directorio acompaña la implementación de Synqo como guion de clase. No es fuente de requisitos ni sustituye la SPEC, los ADR, OpenAPI o el código: explica cómo leerlos y aplicarlos.

## Recorrido recomendado

1. [Formación 0 — Cómo trabajamos en Synqo](00-working-with-synqo/README.md).
2. [SPEC-001 — Bootstrap del repositorio y toolchain](spec-001-bootstrap/README.md).
3. [SPEC-002 — Equipo rápido y acceso de participante](spec-002-quick-team/README.md).

Cada SPEC futura tendrá su carpeta `spec-XXX-slug/README.md`, creada durante el authoring y completada dentro de su mismo Pull Request.

## Principios de uso docente

- Parte de la fuente normativa enlazada; la guía solo añade contexto pedagógico.
- Explica fragmentos pequeños y enlaza al archivo completo, en vez de copiar implementaciones enteras.
- No incluye secretos, cookies reales, tokens ni datos personales.
- Usa Mermaid solo para relaciones que se entiendan peor en texto breve.

La estructura mínima está en [TRAINING-GUIDE-TEMPLATE.md](TRAINING-GUIDE-TEMPLATE.md).
