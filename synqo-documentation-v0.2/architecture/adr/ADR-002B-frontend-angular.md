# ADR-002B — Frontend con Angular

**Estado:** Rejected — alternativa a ADR-002A

## Contexto
Angular fue finalista por su estructura integrada, DI, Router, Signals, Reactive Forms y simetría conceptual con NestJS.

## Decisión
No seleccionar Angular para el frontend inicial. Se adopta ADR-002A (React).

## Motivo
Tras estabilizar los flujos y pantallas se prioriza flexibilidad de composición para calendarios/heatmaps, selección visual y microinteracciones. La estructura adicional de Angular no compensa esa prioridad en este proyecto de una persona.

## Nota
Este ADR se conserva para documentar una alternativa real evaluada; no implica que Angular sea técnicamente incapaz de implementar Synqo.
