# Referencias visuales externas

Esta carpeta contiene material visual aportado como referencia para la identidad y la dirección estética de Synqo.

## Qué copiar aquí

- Brand board de Synqo.
- Mockups exploratorios de tema claro.
- Mockups exploratorios de tema oscuro.
- Imágenes auxiliares de paleta, textura, tono, iconografía o atmósfera visual.

Nombres recomendados:

- `brand-board.*`
- `mockup-light.*`
- `mockup-dark.*`

Se aceptan formatos de imagen o PDF habituales: `.png`, `.jpg`, `.webp`, `.pdf`.

## Finalidad

Estos assets sirven como referencia para:

- paleta de color;
- contraste entre tema claro y oscuro;
- sensación visual general;
- relación entre superficies, fondos y acentos;
- posibles criterios de tono gráfico;
- decisiones posteriores de tokens en `design/03-design-system/`.

## Alcance

Estos assets no son fuente de verdad funcional. No deben usarse para cambiar:

- arquitectura de información;
- flujos de usuario;
- requisitos funcionales;
- reglas de negocio;
- jerarquía de pantallas;
- contenido obligatorio;
- estados de dominio.

Si un mockup contradice `PRD.md`, `product/`, `architecture/` o `design/02-visual-direction/visual-direction.md`, prevalece la documentación consolidada. La referencia visual puede inspirar color y estilo, pero no sustituye los wireframes funcionales ni las decisiones de producto.
