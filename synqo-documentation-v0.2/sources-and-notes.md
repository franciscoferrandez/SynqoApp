# Fuentes y notas de consolidación

## Material de entrada

- Paquete original `architecture-decisions-tfm.zip`, con ADR-001…ADR-020, README, decision register y diagramas.
- Material docente del TFM: `0-b0-introducción.pdf`, `b1-ingeniería.pdf`, `b3-fundamentos-ia.pdf`, `b4-herramientas.pdf`.
- Definición funcional desarrollada durante las fases 1–13 de diseño de Synqo en esta conversación.

## Criterio de actualización

El paquete original declaraba expresamente como diferidos el modelo de dominio definitivo, permisos, lifecycle y modelo de invitados. Este paquete los sustituye por el modelo funcional consolidado sin convertir automáticamente las reglas de producto en ADR.

## Uso del material docente

Se ha utilizado como referencia metodológica para claridad/testabilidad de requisitos, principios KISS/YAGNI y separación de responsabilidades, y para la especificación IA: copiloto especializado, riesgos de alucinación, validación de outputs y distinción entre NLP, RAG y agentes.

## No realizado

No se ha realizado investigación web externa para fijar versiones actuales de librerías, precios de proveedores o requisitos regulatorios. Esos datos deberán verificarse en el momento de implementación si resultan relevantes.
