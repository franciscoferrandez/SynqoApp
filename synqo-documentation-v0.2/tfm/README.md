# Evidencia para el TFM

Esta carpeta conserva evidencia estructurada y ligera para redactar posteriormente la memoria del TFM. Permite reconstruir metodología, evolución, decisiones de diseño, implementación, uso de IA, validación, evaluación IA, desviaciones, resultados, limitaciones, trabajo futuro y comparación entre diseño y sistema construido.

No sustituye Git, las SPECs, ADRs, Change Requests ni los informes de testing. Los referencia en lugar de duplicarlos. Git es la fuente temporal de cambios de código; estos registros indexan y contextualizan evidencia significativa.

No se almacenan conversaciones completas con Codex, prompts enteros, logs completos de terminal, secretos, código sensible ni actividad trivial. No dejar decisiones relevantes únicamente en una conversación con IA o una sesión de terminal: el resultado debe quedar en el artefacto adecuado.

Los documentos finales de la memoria se generarán más adelante a partir de estas evidencias, no dentro de esta tarea.

## Registros

- [`evidence-register.md`](evidence-register.md): índice de artefactos objetivos.
- [`methodology-log.md`](methodology-log.md): hitos metodológicos, no diario personal.
- [`ai-assisted-development-log.md`](ai-assisted-development-log.md): usos relevantes de IA y revisión humana.
- [`milestone-register.md`](milestone-register.md): hitos significativos.
- [`metrics-register.md`](metrics-register.md): métricas con fuente objetiva, sin valores inventados.
