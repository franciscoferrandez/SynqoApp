# Tecnologías de la demo local

> La estructura y las ramas principales de la demo local están decididas; los contratos de cada capacidad se concretan en sus SPEC.

[ADR-COO-001 — Separar interfaz web y API para la demo local](../../05_investigacion-y-decisiones/05_adr/adr-coo-001-estructura-demo-local.md) elige Angular y TypeScript para la web, Symfony con API Platform para el servidor y PostgreSQL para la persistencia. La elección responde a los recorridos interactivos, al acceso simultáneo desde dos navegadores y a la preferencia técnica y objetivo de aprendizaje de la persona impulsora. Tailwind CSS será la base de estilos de la web, con tokens visuales propios para reproducir el prototipo; no se adopta inicialmente una biblioteca de componentes.

**Criterio de versiones decidido por la persona que impulsa Synqo:** priorizar ramas LTS compatibles de Node, Angular y Symfony al seleccionar cada versión para la demo, y revisar también el ciclo de soporte de las demás dependencias principales. La versión mayor de Symfony se consultó expresamente y quedó elegida en 7.4 LTS; cualquier cambio posterior de versión mayor requerirá una nueva consulta. Se comprobará la compatibilidad conjunta con API Platform, PHP y PostgreSQL antes de crear dependencias, y se registrarán las versiones elegidas mediante archivos de dependencias y comandos reproducibles. El contenido anterior de este repositorio no es fuente de reglas funcionales ni de estructura técnica obligatoria de esta entrega.

Según los calendarios oficiales de [Node](https://nodejs.org/en/about/previous-releases) y [Angular](https://angular.dev/reference/releases), Node 24 y Angular 21 están en LTS en el momento de preparar la primera SPEC visual; la [tabla de compatibilidad de Angular](https://angular.dev/reference/versions) admite Node 24 con Angular 21. Se seleccionan Node 24 LTS y Angular 21 LTS para esa SPEC.

Para el servidor se eligen **PHP 8.5, Symfony 7.4 LTS, API Platform 5 y PostgreSQL 18**. Tras plantearse Symfony 8, la persona que impulsa Synqo volvió a elegir expresamente 7.4 LTS para priorizar soporte largo: [Symfony 8.1](https://symfony.com/releases) es la rama estable actual pero finaliza soporte en enero de 2027, mientras [Symfony 7.4](https://symfony.com/releases/7.4) mantiene correcciones de seguridad hasta noviembre de 2029. La [guía de API Platform](https://api-platform.com/docs/core/getting-started/) admite Symfony 7.4; [PHP 8.5](https://www.php.net/supported-versions.php) y [PostgreSQL 18](https://www.postgresql.org/support/versioning/) tienen soporte vigente. Se fijarán versiones menores y de parche compatibles en los archivos de dependencias al crear el código; estas comprobaciones no convierten el soporte de hoy en garantía permanente.

La API y PostgreSQL se ejecutarán con Docker Compose en desarrollo local; Angular se ejecutará localmente con Node 24. El contrato público seguirá [ADR-COO-003 — Usar JSON y Problem Details como contrato de la API](../../05_investigacion-y-decisiones/05_adr/adr-coo-003-json-y-problem-details-como-contrato-api.md): recursos JSON, errores Problem Details y OpenAPI como referencia principal.

La web se diseñará para funcionar en navegador móvil y conservar la posibilidad de empaquetarla después. El contenedor móvil, el proveedor de alojamiento y el servicio de correo no se eligen para la demo.
