## Gate de experiencia de usuario

La fase proporciona recorridos, estados y dirección visual suficientes para comparar alternativas técnicas sin inventar comportamiento de producto. La aprobación visual de los mockups no acredita por sí sola conformidad WCAG 2.2 AA. Las pantallas de [SPEC-COO-001 — Base visual y navegación de Synqo](../08_especificaciones/99_archivadas/spec-coo-001-base-visual-y-navegacion.md) se implementaron y comprobaron para su alcance; la conformidad de páginas y procesos completos sigue pendiente hasta completar la entrega.

## Baseline Readiness focal

**Evaluación histórica: READY_WITH_EXPLICIT_OMISSIONS para el baseline de los dos primeros incrementos; NOT_READY para la entrega completa.** La revisión previa a [SPEC-EQU-001 — Arranque de equipo compartido en la demo local](../08_especificaciones/99_archivadas/spec-equ-001-arranque-equipo-local.md) se reordenó para cubrir primero la base visual WEB. [SPEC-COO-001 — Base visual y navegación de Synqo](../08_especificaciones/99_archivadas/spec-coo-001-base-visual-y-navegacion.md) y [SPEC-EQU-001 — Arranque de equipo compartido en la demo local](../08_especificaciones/99_archivadas/spec-equ-001-arranque-equipo-local.md) quedaron cerradas con la auditoría WCAG completa pendiente para la entrega. La revisión transversal comprobó IDs, enlaces y responsabilidades de área en el árbol Markdown; contrastó producto, dominio, requisitos, flujos, wireframes, arquitectura y testing con el primer incremento. Se corrigió una contradicción entre la regla de fecha única y la acción de retirar una fecha seleccionada, y se separaron los drivers del correo real y las copias del piloto posterior. Desde aquella evaluación se cerraron [SPEC-DIS-001 — Disponibilidad diaria y visor del equipo](../08_especificaciones/99_archivadas/spec-dis-001-disponibilidad-diaria-y-visor.md), [SPEC-CON-001 — Crear una consulta con opciones de texto](../08_especificaciones/99_archivadas/spec-con-001-crear-consulta-texto.md) y [SPEC-CON-002 — Crear una consulta de fechas](../08_especificaciones/99_archivadas/spec-con-002-crear-consulta-fechas.md). Esta actualización de estado no sustituye un nuevo gate de readiness global; la auditoría WCAG completa y los valores finales del sistema visual siguen pendientes.

## Perfil objetivo e inventario de investigación

Se adopta provisionalmente el perfil **estándar** del Playbook para el producto completo: equipos, disponibilidad y consultas con datos persistentes, integración de correo y evolución móvil próxima. El objetivo inmediato es la demo operativa local delimitada en [REL-001 — Demo local operativa de Synqo](../01_producto/10_entregas/rel-001-demo-local-operativa.md); la preparación del piloto publicado y de su operación puede seguir después.

La decisión anterior de exigir la base de todo el piloto antes de programar ha sido reemplazada por una dirección más reciente: **centrar la preparación en una demo local operativa**. El alcance concreto está fijado en [REL-001 — Demo local operativa de Synqo](../01_producto/10_entregas/rel-001-demo-local-operativa.md). Los estudios de alojamiento, copias y publicación ya realizados se conservan para una entrega posterior y no bloquean el inicio de la demo. La aplicación móvil instalable también permanece fuera de este primer gate.
