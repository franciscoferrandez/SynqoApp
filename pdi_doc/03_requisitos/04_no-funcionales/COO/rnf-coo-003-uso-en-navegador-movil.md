# RNF-COO-003 — Uso adaptable en navegador móvil

## Requisito

La aplicación web de la primera entrega debe permitir usar desde un navegador móvil las mismas capacidades incluidas en esa entrega, con una presentación adaptable al tamaño de pantalla.

## Contexto

Aplica a la creación y acceso a equipos, identidad de participante, calendario y disponibilidad, y creación, voto y resolución de consultas. La primera entrega no requiere una aplicación móvil instalable.

## Métrica / umbral

Los recorridos funcionales de la primera entrega se pueden completar en una pantalla móvil desde el navegador, sin depender de una vista de escritorio ni de instalar una aplicación. Los tamaños y navegadores concretos para la matriz de verificación se definirán antes de comprobar la entrega.

## Evidencia prevista

Pruebas de los recorridos completos en navegadores móviles dentro de la matriz de verificación que se establezca, junto con la comprobación de presentación adaptable y accesibilidad de [RNF-COO-002 — Accesibilidad web WCAG 2.2 nivel AA](rnf-coo-002-accesibilidad-web.md).

## Origen

Decisión expresa de quien impulsa Synqo: en la primera entrega basta la web adaptable al navegador móvil; una aplicación instalable será requisito de una entrega próxima, con intención inicial de reutilizar el desarrollo web sin tecnología elegida aún.
