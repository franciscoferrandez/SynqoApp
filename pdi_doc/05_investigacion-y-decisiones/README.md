# 05 — Investigación y decisiones

## Propósito

Separa conocimiento recopilado de decisiones aceptadas.

## Contiene

Research, Spikes, alternativas, RFC y ADR.

## No contiene

requisitos ya aprobados duplicados

## Cuándo se utiliza

Lee esta carpeta cuando la fase o una skill necesite crear, revisar o consultar este tipo de conocimiento.

## Cómo se obtiene

Pregunta → investigación → opciones → evaluación → decisión → ADR cuando aplica.

## Preguntas que debe realizar el LLM

¿Qué desconocemos? ¿Qué evidencia decide entre opciones?

## Mandamientos

1. Research no decide.
2. ADR no reemplaza Research.

## Salidas posibles

investigación/decisiones

## Criterios de calidad

- El contenido tiene origen o justificación identificable.
- No duplica una fuente normativa existente.
- Las referencias a artefactos existentes usan `[ID — denominación](ruta/relativa.md)` y apuntan al archivo citado.
- Las incertidumbres relevantes quedan explícitas.
