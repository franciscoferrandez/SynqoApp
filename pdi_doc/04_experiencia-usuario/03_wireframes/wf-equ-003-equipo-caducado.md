# WF-EQU-003 — Equipo caducado

## Flujo

[FLUJO-EQU-001 — Entrar en un equipo y elegir identidad](../02_flujos/flujo-equ-001-entrar-equipo.md).

## Estado representado

Una persona abre el enlace de un equipo que ya ha caducado. El contenido del equipo no es accesible, aunque todavía no se hayan borrado sus datos.

## Jerarquía

```text
┌──────────────────────────────────┐
│ Este equipo ha caducado          │
│                                  │
│ Ya no se puede acceder a él ni   │
│ recuperarlo.                     │
└──────────────────────────────────┘
```

## Acciones

- Comprender que el enlace ya no permite entrar en el equipo.

## Notas

**DEFINIDO:** explicar la caducidad y la imposibilidad de recuperar el equipo sin revelar su contenido. **PROPUESTO:** redacción y disposición final del mensaje. El caso de enlace inválido, inexistente o de equipo ya borrado se representa en [WF-EQU-004 — Enlace de equipo no encontrado](wf-equ-004-enlace-no-encontrado.md).
