# MOCKUP-EQU-004 — Enlace de equipo no encontrado

## Propósito

Revisar la pantalla que aparece si un enlace no identifica ningún equipo, también después del borrado definitivo de uno caducado.

## Vista

[Abrir propuesta navegable](prototipo-equipo-no-encontrado.html).

## Flujo y estado

La vista sigue [WF-EQU-004 — Enlace de equipo no encontrado](../03_wireframes/wf-equ-004-enlace-no-encontrado.md) y [RF-EQU-003 — Acceder al equipo por enlace](../../03_requisitos/01_funcionales/EQU/rf-equ-003-acceder-por-enlace.md). No muestra datos del equipo ni indica si existió anteriormente. Un equipo caducado aún pendiente de borrado usa [MOCKUP-EQU-002 — Acceso a un equipo caducado](mockup-equ-002-equipo-caducado.md).

## Componentes y aspecto

**DIRECCIÓN VALIDADA:** encabezado «No encontramos este equipo», mismo estado para enlace incorrecto, inexistente o de equipo borrado, tarjeta centrada y texto que invita a comprobar el enlace completo. Sigue la dirección visual de las pantallas excepcionales y conserva el selector Automático/Claro/Oscuro. Quien impulsa Synqo ha validado expresamente esta propuesta.
